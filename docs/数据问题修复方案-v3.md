## 1. 真正的根因：三处缺陷叠加（不是一处）

379 个无框页（375 有字 + 4 空字）是被**三个独立 bug 同时**卡住的。只修任何一个，出框数都是 **0**（评审做了消融实验）。

### C1 `select_sentence` 的窗口上限写死 5 行 ← 影响最大

```python
for j in range(i, min(len(lines), i + 5)):   # 只往后看 5 行
```

**379 页里有 244 页（64%）是 6 行以上**，永远匹配不上，直接返回空。

### C2 `clean_sentence` 把带弯引号的词整词丢掉

```python
if any(ord(ch) < 32 or ord(ch) > 126 for ch in tok):
    continue          # sister’s / “Hello, / don’t 整个词被删
```

影响 **403 页 / 2017 个词**。且**自我掩盖**：`word_boxes` 的 run 正则用同样的 ASCII 假设，两层都丢，字母流反而"一致"，框看着是对的——所以这个问题一直没被发现。

### C3 `word_boxes` 的 run 正则同样丢这些词

```python
re.fullmatch(r"[A-Za-z][A-Za-z'’,.!?\-]*", w)   # 以弯引号开头/结尾 → 拒绝
```

丢掉 **27.9% 的 run、22.8% 的字母**（1876 个 run）。

### 三处全修 + 字母偏移 + 同 run 合并 → 378/379 页出框

| 组合 | 出框页数 |
|---|---|
| 只修 C2 | 0 |
| 只放宽 C3 | 0 |
| C2+C3 但保留旧 `merge_to_tokens` | 0 |
| **C1+C2+C3 + 字母偏移 + 同 run 合并** | **378/379（99.9% 全库）** |

唯一失败：`GK-035 p11`（"Pop!" 是矢量字，视觉层 0 个 run，任何算法都救不了）。

**必须加的一步**：字母偏移后，把落在同一个 run 的多个 token **合并成一个词**（视觉拼写为准）。不合并 → 335 页出框但其中 51 页相邻框重叠；合并后 378 页、仅 3 页重叠。

## 2. R2：页区间重算（整本对齐），但必须分块

### 精度已验证

同一本书用整本对齐 vs 逐页对齐，词起点差 **中位 0 ms / p90 20–30 ms**，无跨页滑移。

### 收益已验证（最差的书）

`G1-061`（150.6 s / 231 词 / 8 页），旧 vs 新词速：

| 页 | 旧 | 新 |
|---|---|---|
| 2 | 8.05 | 2.30 |
| 4 | 10.74 | 1.83 |
| 5 | **22.12** | 1.68 |
| 6 | 13.28 | 1.78 |

**0/8 页超 6 词/秒**。另取 5 本"高词速页最多"的书共 48 页，整本对齐后 **0/48 超 6**，词速落在 1.3–3.5。

### 内存与时间（必须分块）

encoder 是 O(T²)：

| 音频 | 峰值内存 | RTF |
|---|---|---|
| 30 s | 669 MB | 0.081 |
| 60 s | 1 215 MB | 0.114 |
| 120 s | **6 688 MB** | 0.123 |
| 210 s | **14 879 MB** | 0.162 |

库里 28 本 >120 s、9 本 >180 s、最长 266 s（~24 GB）。

**方案：分块 encoder（30 s 窗 / 25 s hop，只保留非重叠段），拼 logits 后一次 Viterbi。**

- 实测峰值封顶 **0.67 GB**，帧覆盖 100%，词时间中位 0 / p90 20 ms
- 全库串行 encoder ≈ **29 分钟**（v1 写的 10–20 分钟偏乐观）；6–8 并发安全
- 分块边界尽量落在静音段（现成 `segments` 可用）

### 先决条件：必须先去重

评审实测：把某页文字重复一遍再拼 → 重复页抢走 6.18 s 真实音频，**下一页整页拿不到帧**，其后每页位移最多 −11 s，一路污染到书尾；分块扰动下词时间最大差 **9.28 s**（双稳态）。

所以 **R3 不是"可选"，是 R2 的前置条件**——但 R3 的做法不是"折叠重复句"，而是：

> **同一本书内，两页文字完全相同时，只让第一页进对齐序列，第二页沿用同一区间再按比例切。**

（`G1-061` 的 p7/p8 只是复沓、并不完全相同 → 两页都保留，实测这类不触发双稳态。）

## 3. 判据修正

| v1/v2 的判据 | 问题 | 改为 |
|---|---|---|
| 词/秒 > 6 → 不可信 | 实测 142 页命中，但只漏检 70+ 页；且 3 个 ≤6 词的高词速页区间本身就只有 0.4–0.6 s | 分块对齐后**不用词/秒**，改用 CTC 直接指标：无帧词数=0、单词时长 >2 s、页时长/期望 <0.5 |
| 词框覆盖 ≥95% | 门槛太低 | **≥99%**（实测可达 99.9%） |
| 逐词可用 1200 页 | 没有依据 | **≥1350 页**（941 + 378 中约 330 页可对齐） |

儿童朗读 2–4 词/秒；6 词/秒 = 360 wpm，人念不出来 → 阈值不会误杀 `Huff! Puff!`。

## 4. 执行顺序（原子性要求）

> 改文字必然改词数 → `align_library` 的 `len(spans) != n` 会丢时间戳。
> 评审实测：仅改清洗不重对齐，**53 页会静默丢时间戳**，90 个当前可用页退化。

| 步 | 内容 | 预计 | 验收 |
|---|---|---|---|
| **P1** | C1/C2/C3 三处修复 + 字母偏移 + 同 run 合并 | 1 分钟（纯 CPU） | 379 → 378 页出框；**已有 1063 页框 IoU 中位 1.000、933 页完全一致、0 页变少** |
| **P2** | 同书重复页去重策略 | 秒级 | `G1-061` 不再触发双稳态 |
| **P3** | R2 分块整本对齐，替换 `pick_alignment` + `repair_page_audio` | 串行 29 min，8 并发 ~5 min | 无帧词 0、单词 >2 s 的页 0、页区间覆盖 ≥95% 语音段 |
| **P4** | C4 行级批注过滤 | 秒级 | 4 页正文恢复（`GK-045 p4/p5/p8`、`G1-080 p4`） |
| **P5** | 全量体检 + 108 断言 + 变异 | 10 min | 见下 |

P1–P4 必须同批发布：它们共同决定 `text` / `wordBoxes` / `wordTimes` 的索引一致性。

## 6. 新增的测试（评审要求）

1. **两个词不得共用同一框**（拆词不合并的征兆；现有 T4 的 Voronoi 吸附抓不到）
2. **点图必须有反应**：任取 10 个曾经无框的页，点击后 `stopAt !== null`
3. **页边界不留缝**：相邻页 `audio[1]` 与 `audio[0]` 的间隙 ≤ 0.3 s（除非中间是静音段）
4. **空文字页不静默失败**：`GK-045` 的 4 页要么有文字、要么 UI 明确显示"本页无文字"

## 7. 不做的事

- **不折叠同页重复句**：38 处里 34 处是拟声/复沓（`Crack!` `Yum!` `Trip-trap.`），音频本来就念多遍
- **不整本一次前推**：266 s 书要 24 GB
- **不用比例分配当主力**：178 个 A≠B 页的字母数 p90 差 11.8%（约一个词宽），不是"偏几像素"；优先用**词级 LCS 剔除多余词再重映射**（实测救回 43 页），比例分配只作最后退路并打 `approx`
