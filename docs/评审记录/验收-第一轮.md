## 2. 发现的问题（按严重度）

### 高：新补页大面积“毫秒级词段”，点词功能实际不可用

| 维度 | 实测 |
|---|---|
| <20ms 词段 | **4455 个，分布在 267 页** |
| <40ms 词段 | **5768 个，分布在 379 页（占 1442 页的 26.3%）** |
| 占全部词段 | <40ms 占 **31.0%**（5768/18577） |
| GK | 370/3379 = **10.9%** 词段 <40ms |
| G1 | 5398/15198 = **35.5%** 词段 <40ms |
| 修复前已有 wordTimes 的 738 页 | **0 个 <40ms 词段**（重对齐没有破坏原有页，问题集中在新补页） |
| 真实点词实测（B6） | GK-004 p11 “bird” **17ms**；GK-043 p4 “The” **17ms**；GK-045 p6 “my” **5ms**（点下去就是一声爆音/静音） |

根因：`fix_wordtimes.py` 把 CTC 的 null 词按“左右邻居间隙均分”，没有最小时长下限；间隙小到放不下时只有 20 页触发整页均分兜底，其余大量页产生 5–40ms 的“词”。
影响：这些页原先点词是回落整句（可听），现在点词只播几毫秒——用户感知上比修复前更差。
建议：`_split_run` 增加 `min_dur`（如 0.12s）；放不下就整页兜底或干脆保留无 `wordTimes`（回落整句）；对“文本词数 / 音频时长”严重不匹配（>8 词/秒）的页不应强行生成词级时间轴。

### 中：379 页有 wordTimes 但没有 wordBoxes

GK 15 页 / G1 364 页。覆盖率达标，但这些页**图上文字点不了词**，只能在底部句子栏点词。原有问题（修复前 37 页带时间戳无词框），本次新增了 342 页。

### 中：GK 实际是 559 页，不是 560

GK 70 本 = 69×8 + 1×7。GK-042（The Puppet Show）源 PDF 共 11 页，正文只有第 4–10 页，第 11 页是只有页码的封底、无文字。硬指标只能按 **559/559 = 100%** 记；“560/560”在现有资源上无法字面达成（强补只会多一个空文字页）。文档口径需要同步。

### 中：部分页“文本 ≫ 音频”，时间轴结构合法但语义不可信

34 本书仍是 `alignMethod: "window"`（GK 5 本 / G1 29 本），页音频区间可能整体错位。典型：G1-061 p7 48 词 / 4.47s，G1-107 p8 92 词 / 4.67s；全库 **96 页 >8 词/秒**（GK 11 / G1 85）。另外官方确认 20 页使用“整页均分”兜底（全 G1，见 FIXER-DONE 第 7 节）。这些页的 wordTimes 只保证结构合法，不保证和语音对应。

1. 3 页 GK 的 `text` 是 PDF 生产批注而非绘本正文（GK-045 p4/p5/p8：“interior art will have…”、“Art page Adjust coat…”），这些页的 wordTimes 语义不可信；另有 5 页正常短句页无词框（GK-016 p11、GK-019 p8/p11、GK-037 p11、GK-066 p11）。
