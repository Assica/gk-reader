## 5. 剩余风险（按严重度）

1. **音频内容 0 覆盖（高）**：`GK-001.m4a` 换成等长静音，95/95 全绿。同类的"静音/音量过低/声道错"完全无断言；
   `qa_library.py` 也只查文件存在和 `pages[].audio` 区间合法性，不查能量。**必须补音频 RMS/峰值检查**（webtest 或 qa 都行）。
2. **qa_library.py 仍未加内容级检查（高）**：任务里说的"图片方差、音频 RMS"没有落地。现在只有 `<6000 B` 体积阈值，
   实测 9.0 KB 纯灰封面直接通过。任何"结构合法、内容错"且体积正常的坏图都不会被告警。
3. **页图只覆盖 9/1442 页（中）**：`T16` 固定采 GK-001/GK-035/G1-001 各 p1/p3/p5。抽样外页图变白 → 95/95 全绿。
   若发生"某本书裁错页"的局部事故，T16 大概率抓不到。
4. **封面只覆盖 24/180 张（中）**：`T15` 用 `slice(0,24)`（按 DOM 顺序 = GK-001…GK-024）。抽样外封面变白 → 全绿。
   对"全库性白纸"这类整类缺陷够用（24 张全白必红），但对"部分封面坏"不够。
5. **文字内容（乱码）仍无断言（中）**：没有任何断言校验 `pages[].text` 的字符是否合法；qa 只查 `text.strip()` 非空。
   （本轮我没做文字变异，此项是代码审阅结论；lead 自己的 `audit_coverage.py` 也把"文字提取/是否乱码"列为 ❌。）
6. **阈值可被"有噪声的平坦图"绕过（低）**：`sd >= 12` 判据下，一张加了强噪声的纯灰图 sd≥12 会通过；
   而"95% 白 + 小 logo"会红。这是方差判据的固有局限，不是本轮缺陷。
7. **T8 有 flake（低，与内容无关）**：10 次整套里 1 次（M1 那轮）`T8` 在 `reloadAt` 等 `pageImg` 时超时，
   导致该轮 total=94。属既有的 reload 等待不稳，不是新断言引入，但会污染红绿判断，建议同样加重试或改用 `Page.reload` + 事件等待。
8. 并发风险：两个 webtest 同时连 CDP 9223 会互相导航，产生假红（我第一轮就中招：T6.4 实际=0、T7 崩、T8.2=-0.04）。
   跑整套前先确认只有一个 runner。
