## 3. 时间戳硬指标（我从 1443 页 JSON 自己算，不采信汇报）

- 结构合法性（1080 个有 tw 的页）：
  - 页 `audio[1] > audio[0]`、不重叠、按页序递增、不超整本 duration：**0 违规**

**语义层面的假阳性（比结构更重要）**：
- 22 页的 `text` 是 PDF 水印 `Heinem ann`（Heinemann 出版社版权水印）而不是图上印的句子；其中 **12 页还带 wordTimes**，被计入 1080"可用页"。
