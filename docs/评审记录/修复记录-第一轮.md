## 1. 改了什么

### 1.1 `tools/ctc_align.py` — 修 `widen()` 的单调性（核心）

旧实现：

```python
if b - a < min_dur:
    b = min(clip_len, a + min_dur)     # 向后顶，可能越过 a_{i+1}
```

短词（CTC 只给到 1–2 帧）会因此产生 `b_i > a_{i+1}` 的重叠区间，随后校验器把
**整页** `wordTimes` 丢掉。这就是 704 页消失的直接原因。

新实现：

- 最小时长不够时**向前借**（本质是 `a = b - min_dur`），由一次前向 + 一次后向约束
  传递统一保证：`0 <= a_0 < b_0 < a_1 < b_1 < ... <= clip_len`；
- 预留给缺失词（`None`）的位置：相邻两个有效词之间如果隔着 CTC 失败词，两侧只收到
  自己的紧边界，不再用中点把缺失词的音频吃掉；
- 为四舍五入留出余量（`min_dur + 2ms`、词间 `gap + 2ms`），保证**写进 JSON 的毫秒值**
  仍然满足"每段 ≥ 0.12s、严格递增"；clip 装不下时按比例收缩最小值，但绝不打乱顺序；
- `onnxruntime` 改为在 `_init()` 里懒加载，这样 `widen()` / `words_of()` 和自检脚本
  在没有 ORT 的机器上也能跑。

### 1.2 `tools/fix_wordtimes.py` — 只填不丢

- 保留：`len(wordTimes) != 词数` → 丢该页（**现在这是唯一会丢页的条件**）；
- 缺失词按"左右邻居之间的空隙均分"插值，连续多个 null 各占一份，不再出现同一段
  重复填给多个词；
- 删除"单段过长 / 非单调 / 越界 → 整页丢弃"的启发式；改为把值收进 `[0, page_duration]`；
- 万一某个间隙小到放不下（例如 10ms 要分给 23 个词），用**整页均分**兜底，
  仍然保留 wordTimes（本轮 20 页，见"已知问题"）；
- 写文件用 `io.open(..., encoding='utf-8', newline='')`，无 BOM；
- 输出统计：补了多少词、丢了几页、兜底几页、缺 wordTimes 几页、修完合法几页。

### 1.3 `tools/selftest_widen.py`（新增）

随机 200 组 span + 3 组边界用例（短词回归 / 极短 clip / 全 None / 空输入），断言：

- 输出长度与输入一致，`None` 位置保留；
- 每段 `a < b`，且 `b - a >= min_dur (0.12)`；
- 相邻保留段严格递增（`b_i < a_{i+1}`）；
- 全部落在 `[0, clip_len]`。

运行：`python tools/selftest_widen.py` → `PASS：200 组随机 span + 3 组边界用例...`
