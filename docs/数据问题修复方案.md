# 数据层问题修复方案

> 现状：180 本 / 1442 页；逐词点读可用 941 页（65.3%）。
> 本文针对剩下 501 页不可用的四类根因，给出方案与取舍。

---

## 0. 一句话结论

**四类现象，两个根因**：

| 根因 | 造成的问题 | 页数 |
|---|---|---|
| **R1 文字层与视觉层词汇不一致**（PDF 把 `little` 拆成 `lit tle`） | 375 页无词框 → 图上点不了词 | 375 |
| **R2 页-音频区间靠"静音切段"猜**，遇到多句页/静音多的页就切错 | 67 页文字≫音频、115 页长段 | 115 |
| R3 文字层重复（同一段出现在相邻页） | 3 本书重复句 | 3 |
| R4 印前批注被当成正文 | 4 页无字 | 4 |

---

## 1. R1：文字层与视觉层词汇不一致（375 页）

### 证据

`GK-019 p4`：

```
视觉 run : I | am | a | little | cat.        ← 正确
提取文字 : "I am a lit tle cat."              ← little 被拆成 lit tle
```

`select_sentence()` 用"去掉所有非字母"归一化后能匹配整行，所以 `textBox` 是对的；
但 `merge_to_tokens()` 要求 **token 逐个相等**，`lit`+`tle` ≠ `little`，于是返回 `None`，
`wordBoxes` 为 null。

### 方案：字母偏移对齐（letter-offset alignment）

不做 token 相等匹配，改成**字母序列对齐**：

1. 把视觉 run 序列拼成字母流 `A = "iamalittlecat"`，记录每个 run 的 `[起, 止)` 字母下标
2. 把文字 token 序列拼成字母流 `B = "iamalittlecat"`，记录每个 token 的 `[起, 止)`
3. 若 `A == B`（去大小写/去标点后），则 token 的字母区间直接映射到覆盖它的 run 区间
4. token 的包围盒 = 这些 run 的并集
5. 若 `A != B`（真的不一致），退化为"按字母长度比例分配"，并打 `boxQuality: "approx"`

### 预期收益

- 375 页恢复词框（图上可点词）→ 逐词点读可用页数从 941 上探到 **~1300+**
- `textBox` 不变，风险低
- 天然兼容 `little` / `lit tle` 这类拆词，也兼容连字符换行

### 风险

- 若 `A != B`（提取文字真的缺词），比例分配会给出近似框 → 允许点中，但框可能偏几像素。用 `boxQuality` 标记，测试只对 `exact` 的页断言精确落点。

### 验收

- `wordBoxes` 覆盖率 ≥ 95%（1442 页里 ≥1370 页有词框）
- 抽样 20 页人工核对：框落在词上、不跨行
- 点词命中测试（现有 T4 系列）在新页上仍 0 误命中

## 2. R2：页-音频区间靠静音切段猜（67 超长页 + 115 长段页）

### 证据

| 页 | 文字 | 音频 | 词/秒 |
|---|---|---|---|
| `G1-061 p8` | 48 词 / 8 句 | 2.17 s | **22.1** |
| `G1-061 p7` | 48 词 / 8 句 | 4.47 s | **10.7** |
| `G1-059 p9` | 44 词 / 6 句 | 4.53 s | **9.7** |
| `G1-071 p5` | 45 词 / 8 句 | 19.15 s | 2.35（正常） |

同一本书里 `G1-061 p7` 与 `p8` 文字**完全相同** → 至少有一页的文字或音频区间是错的。

根因：现有流程是
```
音频 → 静音切段 → 按 k 段/页分组（k 由"时长规整度"猜）
```
一旦某页是多句、或段间停顿很长，切段数就对不上页数，只能靠猜。

### 方案 A（推荐）：整本联合对齐，取代逐页切段

把"页"从对齐里彻底拿掉：

1. 把一本书**所有页的文字按顺序拼起来**：`T = t1 + t2 + ... + tn`
2. 用整本书的音频对这个 `T` 做**一次** CTC 强制对齐
3. 每页的时间区间 = 该页第一个词的起点 ~ 最后一个词的终点
4. 逐词时间戳**同一次对齐直接产出**，不再需要 `align_library.py` 再跑一遍

一次对齐同时解决：页区间、词时间戳、长段、词速异常。

**代价**：每本书要跑一次长音频对齐（60–120 秒音频），180 本约 10–20 分钟（可并行到 3–5 分钟）。

**风险**：整书对齐对文字与音频的整体一致性要求更高；若某页文字根本不在音频里（批注页），会污染邻近页。缓解：先剔除 `textSuspect` 页再拼。

### 方案 B（保守）：保留现有流程，只加"不可信"闸门

- `words / 页时长 > 6` → 标 `textSuspect`，不出词时间戳，句子栏显示但标注
- `单段 > 2s` → 已做（丢弃该页词时间戳）
- 不动页区间

**代价**：67 页永远没有逐词点读，长段页也只能整句读。**不解决根因**。

### 取舍

选 **A**。B 只是把问题标出来，A 是从机制上消掉它。A 的失败可以回退到 B（保留现有 book.json 快照）。

## 3. R3：文字层重复（3 本）

`GK-056`、`G1-039`、`G1-041` 各有一句出现两次。

### 方案

1. **先判性质**：若重复句在两页上，且两页音频区间不同 → 可能真重复（绘本常重复句式）；若同一页内连续重复且音频只读一遍 → 抽取错误
2. 同页内连续重复的句子做**折叠**（保留一份）
3. 跨页重复不动（可能是真重复），但记入 `dupAcrossPages` 供人工抽查

### 验收

- 同页连续重复 = 0
- 跨页重复清单 ≤ 5 条，人工确认

## 4. R4：印前批注页（4 页）

`GK-045 p4/p5/p8`、`G1-080 p4`。

现在是把整页 `text` 清空。`G1-080 p4` 有误杀风险——它的原文末尾其实有一句正文
"A big red thing made a noise."，被整页清掉了。

### 方案：行级过滤，而不是整页清空

1. 按行切分页面文字
2. 命中批注特征（`interior art` / `Art:` / `Adjust` / `OVERALL:` / `.indd`）的行**删掉**
3. 剩下的行若仍有完整句子 → 保留该页文字与词框
4. 全被删光 → 才置空

### 验收

- `G1-080 p4` 恢复出那句正文
- `GK-045 p4/p5/p8` 仍为空（那三页确实只有批注）
- 全库 `text` 含批注特征的页 = 0

## 5. 执行顺序与验收

| 步骤 | 内容 | 预计 | 验收 |
|---|---|---|---|
| 1 | R1 字母偏移对齐 | 改 `select_sentence`/`merge_to_tokens`，重跑 `--boxes-only` | 词框 ≥95%，抽样 20 页人工核对 |
| 2 | R4 行级过滤 | 改文字清洗 | 批注页 0 残留，G1-080 p4 恢复 1 句 |
| 3 | R3 同页去重 | 改文字清洗 | 同页连续重复 = 0 |
| 4 | R2 整本联合对齐 | 新脚本 `align_book.py`，替换切段+逐页对齐 | 词/秒 ≤6 的页 ≥98%；长段 >2s 的页 = 0 |
| 5 | 全量体检 + 测试 | `audit_content` + `webtest` + `mutation` | 108 断言全绿、变异 11/11、内容体检 0 问题 |

**回退**：每步前对 `library/` 做快照（manifest + book.json 的 sha256 清单），失败即还原。

**不做的事**：
- 不改 `web/` 的交互逻辑（除非 R1 需要暴露 `boxQuality`）
- 不降低任何现有测试断言
- 不动 `tools/webtest.mjs` 里的容差

---

## 6. 需要专家拍板的三点

1. **R2 选 A 还是 B**：A 是重写对齐入口（风险中、收益大），B 是标注不可信（零风险、不解决根因）
2. **R1 的近似框是否可接受**：`A != B` 时用比例分配给出近似框，还是干脆不出框（更保守但会少几页）
3. **R3 跨页重复是否算缺陷**：绘本本身可能重复句式，需要产品判断
