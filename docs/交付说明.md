## 2. 怎么跑

```powershell
python tools/serve.py --port 8787 --dir "E:\apple app"   # 预览 http://127.0.0.1:8787/web/
python tools/preflight_ci.py                              # 推送前自检（38 项）
```

```powershell
# 测试（Edge 必须带 --autoplay-policy=no-user-gesture-required，否则 T9 必挂）
& 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe' --headless=new --disable-gpu `
  --no-first-run --autoplay-policy=no-user-gesture-required --mute-audio `
  --user-data-dir="$env:TEMP\edge-9223" --remote-debugging-port=9223 about:blank
node tools/webtest.mjs "http://127.0.0.1:8787/web/"
node tools/mutation.mjs                                   # 需要 8790 沙箱服务
python tools/qa_library.py                                # 结构
python tools/audit_content.py --jobs 8                    # 内容（封面/页图/音频）
```

