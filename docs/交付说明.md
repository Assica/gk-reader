## 2. 怎么跑

```powershell
# 本地预览
python tools/serve.py --port 8787 --dir "E:\apple app"
# 浏览器打开 http://127.0.0.1:8787/web/
```

```powershell
# 测试（需要 8787 服务 + 9223 调试端口）
# 注意：Edge 必须带 --autoplay-policy=no-user-gesture-required，
#       否则无头浏览器会拦截音频自动播放，T9「整本连播」必然失败（这是环境不是产品）
& 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe' --headless=new --disable-gpu `
  --no-first-run --autoplay-policy=no-user-gesture-required --mute-audio `
```

## 2.5 打包前自检（强烈建议先跑）

CI 的 macOS 构建额度宝贵，本地能验的先验：

```powershell
python tools/preflight_ci.py
```

它会检查：依赖 lock 是否与 package.json 一致、`npm ci --dry-run` 能否解析、
`www` 产物齐不齐、workflow 是否还写死 `-workspace`、
原生补丁脚本能否在真实 Capacitor 模板上跑通、plist 关键项是否写入。

**已确认并修掉的三个 CI 杀手**（都是本地用真实模板验证出来的）：

| 问题 | 后果 | 修法 |
|---|---|---|
| `plutil -replace UIStatusBarHidden` | 模板里没这个 key，`-replace` 直接报错 → 构建挂 | 改用 `patch_plist.py`（plistlib，缺则新建） |
| `AppDelegate` 找 `return super.application(...)` | Capacitor 7 模板没有这行 → 脚本 `exit(1)` | 改成定位 `didFinishLaunchingWithOptions` 函数体插入 |
| `pod install` + `-workspace App.xcworkspace` | Capacitor 7 默认 SPM，没有 Podfile/workspace → 两步都挂 | 按 `if [ -f Podfile ]` 分支，SPM 走 `-project` |

## 4. 已知问题（按严重度）

### 阻塞级

| # | 问题 | 影响 |

| B1 | **6 本书完全没有逐词时间戳**：`GK-051` `GK-055` `G1-031` `G1-091` `G1-094` `G1-109` | 只能整句读；其中 3 本连词框也不全，单靠重算时间戳救不回来 |

| B3 | ~~测试不稳定~~ **已澄清**：三次连跑稳定 109/109 | 之前的抖动是两个环境因素：① 无头 Edge 未开 `--autoplay-policy`，T9 连播必然超时；② 多个 agent 并发抢同一个 9223 调试端口。CI 里固定启动参数 + 独占端口即可复现绿 |

## 5. 发布判断

| 场景 | 结论 |
|---|---|
| 家里自己用（孩子试读） | **可以**，核心链路（开书/点读/连播/语速/进度）是通的，数据无损坏 |
| 给别的家长用 | **不建议**，B2 水印页会让人一眼看出数据没做干净 |
| 上架 | **不可行**，版权 + B1/B2/B3/B4 |

## 6. 如果要修，建议顺序

1. **B2 水印页**（22 页）：在文字清洗里识别 `Heinem ann` 这种水印串，直接剔除该页文字 —— 半天
2. **B3 测试稳定性**：把 4 个 flaky 用例的等待条件改成事件驱动（而不是固定 sleep）—— 一天
3. **B4 补时间戳**：185 页里有框的可以直接重跑对齐 —— 半天
4. **B1 六本书**：需要先修页区间（整本联合对齐，分块 30s 窗口）—— 两三天
5. **N1/N2 页区间**：同上
